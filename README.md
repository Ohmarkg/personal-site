# Mark Gonzalez — Portfolio

Next.js App Router, TypeScript, Tailwind CSS, Motion for React, and Lucide React.

## Setup

Use Node.js 22 or newer.

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

```sh
npm run typecheck
npm run build
npm start
```

Feature implementation continues on separate branches. No deployment or paid service is configured.
